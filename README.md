# Измерение скорости скачивания

Консольный скрипт на Python: выполняет **10 последовательных GET-загрузок**
указанного HTTP(S)-ресурса и каждый раз читает тело ответа до конца.
Печатает среднее время запроса, общий объём данных и скорость скачивания.

## Запуск

Нужен **Python 3.10 или новее**. Сторонних зависимостей нет.

```bash
git clone https://github.com/justusmisha2026/anketa_etolegko.git
cd anketa_etolegko
python3 download_speed.py "https://www.python.org/static/img/python-logo.png"
```

Вместо примера можно передать адрес нужной картинки или другого ресурса.
URL лучше заключать в кавычки, особенно если он содержит `&`.
В Windows вместо `python3` можно использовать `py -3`.

```bash
python3 download_speed.py "https://www.python.org/static/img/python-logo.png" --timeout 60
python3 download_speed.py --help
```

`--timeout` — положительное число секунд, по умолчанию `30`. Это тайм-аут
блокирующей сетевой операции, например ожидания данных, **не общий лимит
длительности загрузки**. Для остановки длительного замера нажмите Ctrl+C.

Пример формата вывода с условными данными: каждый из 10 ответов содержит
1 MiB и скачивается за 0,5 секунды.

```text
Выполнено запросов: 10
Среднее время запроса: 0.500000 с
Всего скачано: 10485760 байт (10.000000 MiB)
Скорость скачивания: 2.000000 MiB/s
```

## Методика и единицы

- Время измеряется в **секундах** через `time.perf_counter()`: от начала запроса
  до полного чтения и закрытия ответа. Включает установку соединения, ожидание
  сервера, редиректы и получение тела; вывод в консоль в замер не входит.
- Объём — фактически прочитанные **байты тела** конечного ответа. HTTP-заголовки,
  тела промежуточных редиректов и служебный трафик TCP/TLS не учитываются.
- Скорость выводится в **MiB/s** — мебибайтах в секунду.
  **1 MiB = 1024 × 1024 = 1 048 576 байт**. Это байты, а не биты.

Для размеров `b₁ … b₁₀` и длительностей `t₁ … t₁₀`:

```text
общий объём = b₁ + … + b₁₀
суммарное время = t₁ + … + t₁₀
среднее время = суммарное время / 10
скорость MiB/s = общий объём / суммарное время / 1 048 576
```

Например, `10 × 1 048 576 / (10 × 0,5) / 1 048 576 = 2 MiB/s`.
Итоговая скорость вычисляется по общему объёму и времени, а не усреднением
скоростей отдельных запросов.

Тела конечного ответа и промежуточных редиректов читаются блоками по 64 KiB
и не сохраняются на диск. Скрипт запрашивает
`Accept-Encoding: identity`; если сервер всё же прислал сжатое тело, учитывается
его полученный размер без распаковки. Редиректы обрабатывает `urllib`:
10 загрузок могут включать дополнительные HTTP-запросы при перенаправлениях.

Результат характеризует загрузку выбранного ресурса в момент запуска.
На него влияют сервер, кэш, задержки и сеть; это не универсальная оценка
пропускной способности интернет-соединения.

## Ошибки

При HTTP-ошибке, сетевом сбое, тайм-ауте или обнаруженном обрыве тела скрипт
останавливается: сообщает номер неудачного запроса в stderr и возвращает код `1`.
Повторных попыток нет; итог неполной серии не выводится. Некорректные аргументы
дают код `2`, Ctrl+C — `130`, успешный замер — `0`.

Для ответа с `Content-Length` проверяется соответствие прочитанного размера;
обрыв chunked-ответа обрабатывается как ошибка. Если сервер обозначает конец
тела только закрытием соединения, без `Content-Length` и chunked-кодирования,
отличить обычное завершение от преждевременного закрытия невозможно.
Успешный пустой ответ учитывается как 0 байт.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют стандартную библиотеку и локальный HTTP-сервер.
Проверяют формулы, последовательность 10 загрузок, ожидание полного тела,
редиректы с большим телом и циклы перенаправлений, chunked-ответы,
ответы без размера, пустые ответы, HTTP-ошибки,
тайм-ауты, обрывы и аргументы CLI. Доступ в интернет не нужен.

Документация используемых API:
[urllib.request](https://docs.python.org/3/library/urllib.request.html#urllib.request.urlopen),
[time.perf_counter](https://docs.python.org/3/library/time.html#time.perf_counter).
